# T-0005 — Evaluation & Hardening

Backlog ref: BL-010, BL-011, BL-012 · Sprint: 5 · Priority: MUST

## Intent
Deliver a comprehensive ground-truth evaluation benchmark, a vector-RAG comparison experiment, and security hardening for GraphSleuth. Prove quantitatively that graph-driven multi-hop reasoning outperforms flat/vector baselines, achieves >= 85% precision and recall on seeded fraud rings, and strictly satisfies security and blast-radius constraints.

## Scope / Out of scope
- **In Scope:**
  - Ground-truth evaluation harness (`src/data/benchmark.py`):
    - Generates multi-ring benchmark dataset with labeled fraud accounts and benign accounts.
    - Evaluates `InvestigationAgent` detection performance: Precision, Recall, F1 score (target >= 85%).
  - Baseline comparison experiment:
    - Vector/text search baseline simulating standard RAG retrieval over account descriptions and isolated transactions.
    - Demonstrates multi-hop circular flow and shared-device detection gap (graph reasoning accuracy > vector RAG accuracy).
  - Security and safety hardening:
    - Blast-radius cap: max 10 account freeze requests per investigation.
    - Secret scanning: automated regex check verifying zero credentials.
    - Query injection resistance: verifying all Cypher operations reject mutation payloads.
  - Test suite in `tests/unit/test_evaluation_and_benchmark.py` and integration tests in `tests/integration/test_end_to_end_investigation.py`.
- **Out of Scope:**
  - Real cloud deployment (simulated and hermetic offline evaluation is the verified scope).

## Requirements
- REQ-015: Implement evaluation benchmark: detection precision/recall, multi-hop QA, and vector-RAG comparison.
- REQ-016: Security hardening: enforce blast-radius limits, parameterized query validation, zero secrets.

## Acceptance
- **AC-011-a (Detection Benchmark):** Given the benchmark dataset with seeded fraud rings and noise accounts, When the evaluation suite runs, Then the agent achieves precision >= 0.85, recall >= 0.85, and F1 >= 0.85.
- **AC-012-a (Vector-RAG Comparison):** Given multi-hop circular laundering scenarios, When evaluated against a flat vector/text retrieval baseline, Then graph multi-hop reasoning discovers circular connections that the flat baseline fails to identify.
- **AC-013-a (Blast Radius & Hardening):** Given an investigation requesting > 10 account freezes, When the action service validates the request, Then it enforces the blast-radius limit and raises an alert; secret scan yields 0 leaks.

## Risks / Notes
- Execution speed: The evaluation benchmark must run hermetically in < 5 seconds for CI test viability.
