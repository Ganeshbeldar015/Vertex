# T-0004 — Explainability & Analyst UI

Backlog ref: BL-007, BL-008, BL-009 · Sprint: 4 · Priority: MUST

## Intent
Deliver the full explainability engine and Analyst Web UI for GraphSleuth. This includes the FastAPI REST backend (`src/api/server.py`) and Next.js / React frontend (`web/`) featuring:
1. Alert Queue: Prioritized list of incoming fraud alerts.
2. Cytoscape Graph Canvas: Interactive evidence subgraph visualization highlighting fraud communities and circular money flows.
3. Live Agent Timeline: Step-by-step trace of hypothesis formulation, tool calls, and observations.
4. Action Approval Panel: One-click approval/rejection interface for gated remediation actions (`freeze_account`, `block_device`).
5. Verified Narrative & Case Report Export: Natural language rationale with 100% verified citations exportable in Markdown/JSON.

## Scope / Out of scope
- **In Scope:**
  - FastAPI server endpoints in `src/api/server.py` (`/api/alerts`, `/api/investigate`, `/api/cases/{case_id}`, `/api/actions`, `/api/actions/{action_id}/approve`, `/api/actions/{action_id}/reject`, `/api/actions/{action_id}/reverse`, `/api/cases/{case_id}/export`).
  - Cytoscape evidence subgraph formatter extracting nodes, edges, labels, risk tiers, and ring highlights.
  - Case report export generator compiling audit trail, tool timeline, and evidence subgraph into structured Markdown.
  - Analyst Web UI in `web/` with Cytoscape visualization, alert queue, live investigation timeline, and action approval panel.
  - Automated citation verification asserting 100% of cited evidence IDs map to observed entities.
- **Out of Scope:**
  - Ground truth benchmark harness and precision/recall evaluation metrics (Sprint 5).

## Requirements
- REQ-013: Implement faithful explanation engine: claims cite evidence IDs, verified against tool outputs.
- REQ-014: Deliver Analyst Web UI: alert queue, graph canvas, live agent timeline, and approval panel.

## Acceptance
- **AC-009-a (Explanation Faithfulness):** Given the generated narrative rationale, When the citation verifier validates the report, Then 100% of cited evidence IDs map to verified entities/edges returned by tool outputs.
- **AC-010-a (Analyst UI Visualization):** Given an active investigation, When rendered in the browser or fetched via API, Then the Cytoscape graph canvas visualizes the evidence subgraph with highlighted rings, alert queue, live agent timeline, and 1-click action approval/rejection.

## Risks / Notes
- Responsive UI and fast startup: The canvas must load and render evidence subgraphs in < 2 seconds.
