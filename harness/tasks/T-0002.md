# T-0002 — Core Graph Algorithms & MCP Tools

Backlog ref: BL-002, BL-003 · Sprint: 2 · Priority: MUST

## Intent
Expose standard graph algorithms (Louvain community detection, PageRank centrality, cycle detection, pathfinding) and graph query utilities (`shared_attributes`, guarded Cypher) as discoverable, typed MCP tools. These algorithmic capabilities enable the agent to uncover hidden fraud ring structures, identify high-centrality money hubs, and trace circular money laundering loops.

## Scope / Out of scope
- **In Scope:**
  - `algo.detect_communities`: Louvain / Label Propagation community detection clustering dense account/device subgraphs.
  - `algo.rank_centrality`: PageRank algorithm scoring hub accounts and transaction routers.
  - `algo.detect_cycles`: Circular money-flow cycle detector tracing transfer paths returning to origin.
  - `graph.find_paths`: Shortest path and multi-hop pathfinding between entity pairs.
  - `graph.shared_attributes`: Finds accounts sharing devices, IPs, addresses, or phone numbers.
  - `graph.run_readonly_cypher`: Guarded Cypher query tool enforcing read-only keyword blocking and LIMIT clauses.
  - Registration of all 6 tools in `SengraMCPServer` with JSON-RPC schemas.
  - Hermetic unit tests in `tests/unit/test_graph_algorithms.py`.
- **Out of Scope:**
  - Multi-agent action execution and human approval UI (deferred to Sprint 3/4).
  - External streaming data pipelines (deferred to Sprint 5).

## Guidance
- Implement algorithms with deterministic fallbacks so they run reliably without requiring C-compiled external libraries.
- Parameterized queries must strictly be enforced; no unparameterized string building.
- Return structured JSON payloads suitable for agent context consumption.

## Requirements
- REQ-002: Property graph schema with indexes and relationships.
- REQ-005: Expose graph algorithm tools via MCP: find_paths, detect_communities, rank_centrality, detect_cycles.
- REQ-006: Expose guarded Cypher tool (`run_readonly_cypher`) enforcing READ-ONLY and LIMIT.

## Acceptance
- **AC-002-b (Community Detection):** Given a subgraph containing the hero ring and legitimate accounts, When `algo.detect_communities` runs, Then accounts sharing devices and circular transfers are assigned to the same community ID.
- **AC-002-c (Centrality Ranking):** Given a network with hub accounts, When `algo.rank_centrality` runs, Then high-traffic accounts receive higher PageRank scores than peripheral accounts.
- **AC-002-d (Cycle Detection):** Given a circular transfer sequence (`A-1042 -> A-1050 -> A-1061 -> A-1042`), When `algo.detect_cycles` runs, Then the exact circular loop is detected and returned.
- **AC-002-e (Pathfinding):** Given two accounts separated by multi-hop links, When `graph.find_paths` runs, Then the shortest connecting path and relationships are returned.
- **AC-002-f (Shared Attributes & Guarded Cypher):** Given target account `A-1042`, When `graph.shared_attributes` runs, Then device `D-77` and linked account `A-1050` are identified; `graph.run_readonly_cypher` successfully executes read queries and rejects mutation queries.

## Risks / Notes
- Algorithm performance on large graphs: cap max hops and iterations to keep tool responses under 2 seconds.
