# T-0001 — Walking Skeleton (End-to-End Slice)

Backlog ref: BL-001 · Sprint: 1 · Priority: MUST

## Intent
Build the thinnest possible end-to-end slice through the complete GraphSleuth system: data generator, graph database engine, MCP tool server (`get_entity`, `expand_neighborhood`), agent reasoning loop, and citation-verified output. This proves the multi-hop architecture and validates all pipeline stages and quality gates.

## Scope / Out of scope
- **In Scope:**
  - Synthetic dataset generator creating accounts, devices, and transactions with 1 seeded 3-hop fraud chain.
  - Property graph engine supporting OpenCypher queries with parameter binding.
  - SENGRA MCP tool server implementing `get_entity` and `expand_neighborhood` tools.
  - Agent orchestrator loop executing plan -> tool selection -> observation -> verdict with cited evidence subgraph.
  - Full stage artifact trail `01-spec.md` through `08-docs.md`.
- **Out of Scope (deferred to Sprint 2-4):**
  - Advanced graph algorithms (Louvain, PageRank, cycle detection - Sprint 2).
  - External banking API mutations (Sprint 3).
  - React/Cytoscape UI frontend (Sprint 4).

## Guidance
- Follow parameter binding strictly (`$param`); no string concatenation in Cypher.
- Agent loop must enforce step budget (max 15 tool calls) and citation verifier (claims cite real tool outputs).
- Fast unit tests (< 1s) with hermetic test graph fixture.

## Requirements
- REQ-001: Ingest accounts, devices, transactions from generator.
- REQ-002: Property graph store with indexes and `TRANSFERRED_TO` relationship.
- REQ-004: Expose graph query tools via MCP (`get_entity`, `expand_neighborhood`).
- REQ-008: Implement autonomous agent reasoning loop.
- REQ-013: Implement faithful explanation citing verified evidence IDs.

## Acceptance
- **AC-001-a (Synthetic Seeding):** Generator generates account nodes, device nodes, and transaction edges including a 3-hop mule chain: `(A-1042)-[:USED_DEVICE]->(D-77)<-[:USED_DEVICE]-(A-1050)-[:TRANSFERRED_TO]->(A-1061)`.
- **AC-002-a (Graph Query Engine):** Graph store executes parameterized Cypher queries and returns structured node/edge dicts.
- **AC-003-a (MCP Tool Dispatch):** MCP tool server responds to `get_entity` and `expand_neighborhood` with valid JSON-RPC schema.
- **AC-004-a (Agent Multi-Hop Traversal):** Agent receives alert on `A-1042`, expands 2 hops, discovers shared device `D-77` and account `A-1050`, returns structured verdict with confidence and evidence citations `[E1, E2]`.
- **AC-005-a (Citation Verification):** Citation verifier validates 100% of cited evidence IDs against tool call outputs.

## Risks / Notes
- Ensure zero external network dependencies in unit tests so CI remains fully hermetic.
