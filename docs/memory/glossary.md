# Glossary

- **Cypher / OpenCypher:** Declarative property graph query language.
- **FalkorDB:** High-throughput graph database using Redis protocol and OpenCypher engine.
- **Mule Account:** Intermediate bank account used to transfer stolen money.
- **Evidence Subgraph:** Smallest induced subgraph of nodes and relationships proving an alert verdict.
- **Handoff Contract:** Machine-validated JSON payload passing work between pipeline roles.
